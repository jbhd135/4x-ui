# 4x-ui

gg 现用面板的独立发行项目。保留当前功能，提供新 VPS 一键安装；不会覆盖原来的 GitHub 项目。

当前版本 `v4.0.7` 支持 `编号|家宽| 日期` / `编号|高速| 日期` 节点名称，快捷创建新增绑定现有 SOCKS5 静态出口的“家宽”开关，以及 `1 / 2 / 4 / 无限 / 自定义` 设备限制。保留快捷创建提速、默认关闭“客户端自动禁用后重启 Xray”、`10G / 20G / 30G / 无限` 日限额和此前修复。来源和构建说明见 [PROVENANCE.md](PROVENANCE.md)。

## 一键安装

支持 **Linux x86_64（amd64）、Debian 12+ / Ubuntu 22.04+、systemd**。推荐全新 Ubuntu 24.04 VPS；暂不提供 ARM 安装包。

先使用 `sudo -i` 进入 root，然后执行：

```bash
curl -fLsS https://raw.githubusercontent.com/jbhd135/4x-ui/main/install.sh -o /tmp/4x-ui-install.sh && bash /tmp/4x-ui-install.sh
```

安装时可以填写用户名、密码、面板端口和访问路径，回车使用随机值。安装完成会显示登录地址和账号。已有 x-ui 的服务器会执行升级，不会额外安装第二个面板。

不指定版本时，安装脚本下载 GitHub 最新正式 Release 的安装包，而不是直接运行 `main` 分支源码。`v4.0.7` 安装包包含新命名、家宽开关、设备限制选项及此前的快捷创建提速功能。

无人值守安装（自动生成账号、密码、端口和路径）：

```bash
bash /tmp/4x-ui-install.sh --yes --no-config-prompt
```

指定版本或登录地址参数：

```bash
bash /tmp/4x-ui-install.sh --version v4.0.7 --port 7878 --web-base-path /panel/ --public-host panel.example.com
```

## 保留的功能

- 共享 Reality 入站与独立客户端，设备数、`10G / 20G / 30G / 无限`日限额、到期管理。
- 自定义名称、MMDD / YYYYMMDD 日期及 1、3、6、12 个月快捷选项。
- 快捷创建成功后后台刷新客户列表；并行读取列表和在线状态，合并重复刷新，防止连续点击重复提交。
- 节点名称以客户识别码开头，再显示家宽 / 高速及短日期；面板支持按识别码搜索。
- 快捷创建可选择家宽出口和 `1 / 2 / 4 / 无限 / 自定义` 设备数，默认家宽关闭、设备数为 1。
- 普通订阅、Clash 订阅及二维码，移动端客户信息。
- 客户端 SOCKS5 静态出口开关，以及当前 gg 版本已有的修复。

## 新服务器须知

- 安装包不带任何生产客户、入站、证书、登录密码或云盘密钥。首次安装是空面板，需自行创建入站或导入自己的数据库。
- 默认使用 HTTP 初始化。正式登录管理前，在面板设置配置域名及有效 HTTPS 证书，或先通过 SSH 隧道访问；同时配置 VPS 防火墙放行所需端口。
- 服务默认时区为 `Asia/Shanghai`，不修改系统时区。日限额默认按北京时间 00:00 刷新；已有数据库和环境文件中的自定义时区保留。
- WARP、SOCKS5 出口账号及运维中心 Google Drive 自动备份不包含在软件发行包中，需在新机器单独配置。
- 不保证网络可达性、解锁效果或防封锁。服务端与客户端仍需正确配置。

## 客户识别码

- 日期型客户名复用原来的 6-12 位字母数字后缀，例如 `20261008-azxd4p` 显示为 `azxd4p|高速| 26-10-08`；客户启用 SOCKS5 静态出口时显示为 `azxd4p|家宽| 26-10-08`。
- 自定义客户名称保留，并在前面加上由客户名称确定的 `c` 开头短码。修改到期时间不改变识别码；修改自定义客户名称会改变该短码。
- 新增客户会校验识别码冲突；快捷创建会避开现有短码。不更改 UUID、密码、端口、客户原名或到期清理规则。
- 复制链接、节点二维码、普通订阅、JSON 订阅和 Clash 订阅使用同一命名规则。多出口的线路备注追加在末尾。
- 老订阅需更新订阅；单链接导入的旧节点需重新导入或手动改名。显示名称不是连接凭据。

## 管理与升级

### v4.0.7 家宽及设备选项

- 快捷创建新增“家宽”开关，绑定该客户的现有 SOCKS5 静态出口设置，不会自动开启其他客户的出口。入站尚未启用有效 SOCKS5 出口时，该选项不可用。
- 设备限制支持 `1 / 2 / 4 / 无限 / 自定义`；无限对应 0，自定义支持 0 到 9999 的整数。重新打开创建窗口时恢复默认 1 台、家宽关闭。
- 默认导出名称为 `编号|家宽| YY-MM-DD` 或 `编号|高速| YY-MM-DD`，编号沿用客户短识别码；自由填写的自定义名称仍保留。原有剩余天数等订阅提示按设置追加。
- 普通订阅、Clash、JSON、复制链接及节点二维码使用同一规则。旧节点需要更新订阅或重新导入才能显示新名称。
- 不修改已有客户的 UUID、原始客户名、到期时间、设备限制或出口开关；已有安装不会仅因升级而切换客户出口。升级仍会重启面板，应安排维护时段。

### v4.0.6 快捷创建提速

- 点击“创建并复制链接”后，保存成功即关闭弹窗，不再等待整个客户列表刷新完毕；复制链接功能保留。
- 保存失败时保留表单；保存成功但后台刷新失败时明确提示已创建，避免重复创建。
- 不修改客户 UUID、名称规则、到期时间、设备限制或流量限额。实际耗时仍取决于服务器保存响应和网络状况。
- 新安装默认获取最新正式版本。已有服务器需执行升级才能获得新程序；升级会重启面板，请选择维护时段。

### v4.0.5 限额处理默认值

- 新安装以及未保存 `restartXrayOnClientDisable` 设置的安装，默认关闭“客户端自动禁用后重启 Xray”。前后端默认值一致。
- 已有数据库中明确保存的开启或关闭状态不会被覆盖。若此前开启，请在面板设置中关闭该开关并保存；仅升级不会替你关闭已保存的开关。
- 正常情况下，超额或到期客户通过 Xray API 禁止建立新连接，不再仅因客户被自动禁用而强制重启整个 Xray。已有长连接可能继续，不保证立即断开；API 失败等原有恢复逻辑仍可能触发重启。
- 不修改客户 UUID、设备限制、日限额数值、到期日期或每日重置时间。安装升级本身仍按原流程重启面板，应安排在维护时段。

```bash
x-ui status
x-ui restart
x-ui log
x-ui setting -show
x-ui update
```

兼容原路径：程序 `/usr/local/x-ui`，数据库 `/etc/x-ui/x-ui.db`，服务 `x-ui`。升级前备份到 `/root/4x-ui-backup-*`，包括停服后的数据库目录和原程序；启动失败会尝试自动回滚。备份含敏感数据，请只由 root 保管。

升级默认保留账号、客户和设置。需要修改登录设置时才使用 `--configure`。`--skip-start` 会初始化登录设置但不启动服务。离线安装需要同一 Release 的 `x-ui-linux-amd64.tar.gz` 和 `SHA256SUMS`：

```bash
bash scripts/install-selfhosted.sh --offline-dir /root/4x-ui-release --yes
```
